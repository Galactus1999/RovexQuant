# Roadmap

0. Foundation: contracts, module boundaries, CI, local mode.
1. Historical research: permitted CSV/bhavcopy import, instrument master, corporate actions, data quality, daily/swing scanner.
2. Backtesting/paper trading: event-driven simulator, realistic costs/slippage, walk-forward validation and signal lifecycle.
3. Intraday: licensed/authorized live or delayed source, session-aware candle builder, reconnect/replay and provider health.
4. Optional Zerodha and Dhan data adapters behind the same provider port; verify current official docs and data-use permissions first. No orders.
5. AI research assistant: DeepSeek, Groq, OpenRouter adapters with secure user configuration; evidence-grounded explanations only.
